# Omar Quinones | Portfolio

My personal portfolio site, where I share who I am, what I'm interested in, the projects I've built, and how to reach me.

**Live site:** [omarquinones.dev]

## Built with

- React (Vite)
- Plain CSS with flexbox and media queries
- Google Fonts (Space Grotesk, JetBrains Mono, Syne)
- Deployed on [GitHub Pages]

## Highlights

- Fully responsive layout for desktop, tablet, and phone
- One shared layout container so every section lines up
- Project cards with live demos and source links
- Glass-style cards and a gradient glow background, all in CSS

## Project structure

```
src/
  components/   Navbar, Hero, About, Projects, Skills, Contact
  App.jsx       puts the sections together
  index.css     global styles and variables
```
